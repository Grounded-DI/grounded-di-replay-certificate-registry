# ExpertScope Opinion-Basis Replay

This self-contained synthetic package traces expert statements to source fragments, records basis and assumptions, evaluates nine separate evidence dimensions, and tests controlled changes to the record.

See [REPORT.md](REPORT.md) for results and limitations. Run `python3 -B run_chain.py input.json run_1`, `python3 -B independent_evaluator.py`, and `python3 -B controls.py` to reproduce the recorded checks.
