# Nitrate screening replay, v2 — input binding correction

Source: US EPA, National Primary Drinking Water Regulations, https://www.epa.gov/ground-water-and-drinking-water/national-primary-drinking-water-regulations, retrieved 2026-11-04. The source table identifies nitrate measured as nitrogen, with MCL 10 mg/L. source_excerpt.txt is a locally prepared textual representation of that retrieved table entry, not a copy of the original page. Sample results are fictional.

Purpose: reproducibly compare a supplied value to 10 mg/L as nitrogen. Values above 10 yield REVIEW_ABOVE; values at or below 10 yield AT_OR_BELOW; missing, invalid, or unsupported units yield HOLD. These labels do not establish compliance, fitness to drink, a regulatory violation, sampling validity or an actual source measurement. Do not use for operational decisions.

The fixture uses S1=4.2, S2=10, S3=10.1 mg/L as N, and S4=12 mg/L nitrate. Independently specified expected decisions: AT_OR_BELOW, AT_OR_BELOW, REVIEW_ABOVE and HOLD. Equality is not above 10. No unit conversion. Decimal strings must match ^[0-9]+(\.[0-9]+)?$; unsupported/missing values or units are held. Malformed JSON or missing sample list is an error. IDs are required and unique. The source digest pin checks the local excerpt against locally selected configuration; replacing both is outside this protection. It does not authenticate the EPA page, a real laboratory result, source selection, or an actor's authority.

Serialization: UTF-8 JSON, sorted keys, compact separators, final LF. Two fresh processes produce exact bytes matching independently frozen expected output and digest; a separately implemented checker recalculates from inputs, pin and output. Controls exercise above/equal/below, unsupported/missing unit, malformed value, changed source, altered decision, changed fixture, and malformed JSON. A crash cannot count as a rejection. Uses Python standard library; no network, notifications or real sampling.

Version 2 correction frozen before implementation: Each result record includes SHA-256 of exact input file bytes as input_sha256. The producer hashes the bytes it parses; the checker separately computes the hash of supplied input bytes and rejects a mismatch with INPUT_MISMATCH and exit 1 before accepting the output. A changed input with the same category must be rejected against the old record. This is an integrity binding to caller-supplied bytes, not authentication of sample origin or laboratory validity. The source and its pin remain jointly mutable as documented above. The v1 package and prior evidence are preserved separately.
