# Frozen contract
2026-11-04; illustrative fictional post-treatment entry-point samples at a fictional community water system; arsenic concentrations. Compare a reported quantified value mathematically against 10 µg/L (= 0.010 mg/L), no regulatory compliance decision, no health assessment. Source configuration is a fixed local source record with exact id EPA_ARSENIC_MCL, threshold "10", unit "ug/L", and URL matching SOURCE.md; missing, changed or extra source fields INVALID_SOURCE/2 with destination absent. This check is against a hard-coded selected source identity, not live-source authentication.

Input JSON: object with source and samples; each sample fields id, context, status, result, unit, reporting_limit. All fields must exist. Context is entry_point or another string. Status quantified or below_limit. Numeric results and reporting limits are nonnegative decimal strings of at most six fractional digits, no exponent, no leading plus, at most 1000000; no binary float. result null for below_limit; result string for quantified; limit always decimal string. unit ug/L or mg/L or any other string (including empty); missing field or invalid values reject INVALID_INPUT/2. Unique ASCII alphanumeric IDs. Exact keys, duplicate JSON object keys rejected. Sample and evidence names are fictional. For each sample precedence: wrong context -> HOLD CONTEXT_OUT_OF_SCOPE; unsupported or empty unit -> HOLD UNIT_UNSUPPORTED; below_limit -> HOLD BELOW_REPORTING_LIMIT (even if reporting limit is below the threshold; avoid false precision); quantified value less than reporting limit -> HOLD INCONSISTENT_RESULT; otherwise compare unrounded using exact decimal arithmetic: >10 ABOVE, =10 EQUAL, <10 BELOW, reason NUMERIC_COMPARISON. No implied quality control, sample authenticity, or legal judgment.

Six canonical UTF-8 JSON records, sorted keys, compact separators, ASCII escaping, newline; sorted sample IDs. 01_source.json = source record. 02_inputs.json = samples (sorted). 03_eligibility.json = [{id, eligible, reason, ug_per_l}] normalized result as canonical decimal string for eligible cases, null otherwise. 04_comparison.json = [{id, comparison, reason}]. 05_report.json = {notice,results}; notice is exact string 'Numerical comparison only; not compliance, safety, or health-risk determination.' results mirror comparisons. 06_commitment.json = object filename->SHA256 raw bytes of 01-05. Hash is commitment, not verifier. Fixed source metadata in output reflects selected source; excerpt separately available in SOURCE.md.

Producer Python3 standard library exits 0 OK; input validation 2 INVALID_INPUT or INVALID_SOURCE, existing destination 2 OUTPUT_EXISTS; checker independently parses input and recomputes all records, exits 0 OK or 1 CHECK_FAILED for missing, malformed, altered, or coherently changed artifacts; invalid input same 2 status. Checker trusts supplied input: if inputs and outputs both replaced coherently it may accept. Producer creates a new destination only; unexpected I/O -> IO_ERROR/3; no atomicity or concurrency guarantees. Both emit one JSON status object. Acceptance: seven fixture cases agree with EXPECTED.md, six artifacts byte-identical across two fresh processes, both accepted by checker, all predeclared challenge tests pass with zero skips. Test system records process exit/status, destination hashes before and after, and inputs.
