## Five-hash contract

Each run contains four canonical records and `canonical_run.zip`. The ZIP contains only those four records in lexicographic order, stored without compression, with fixed 1980-01-01 timestamps, UNIX regular-file mode 0644, no extras, no comments, and no receipts. All five artifacts passed three-way direct byte comparison and SHA-256 comparison. Complete hashes for every run are in the PDF and `verification/three-run-comparison.json`.

Canonical JSON is compact, UTF-8, sorted-key JSON without a final newline, matching the reference serialization style. CSV uses UTF-8, standard CSV quoting, and LF line endings. Assessment text uses UTF-8 with a final LF. No claim of full JCS compliance is made.

`ReplayDivergence` and `StateTransitionMismatch` are zero for the canonical records in this experiment. Within each run, the local replay gate compares two separately parsed evaluations before export. The separate verifier then checks the three actual execution artifacts. These fields do not assert a production runtime history.

The inherited gate names and six-decimal coverage values describe complete coverage of this finite stipulated record: evidence admissibility, law mapping, element support, summary-judgment routing, damages support, and instruction mapping. They are not calibrated statistical confidence measures. Numeric error zero means exact preservation of the unchanged damages values in the records; no damages prediction or numerical approximation is evaluated.

## Reproduce

Python 3.9+ on macOS or POSIX; core execution/verification uses only the standard library. No network or model calls are made.

From the extracted package root:

```sh
python3 -B source/verify_release.py
python3 -B source/verify.py
python3 -B source/acceptance.py
python3 -B source/reproduce.py /path/to/a/new/nonexistent/folder
shasum -a 256 -c SHA256SUMS.txt
```

The reproduce command creates new receipts and evidence in a new folder; it never overwrites this package. Canonical run hashes should repeat; process IDs and receipt timestamps should differ. `source/build_report.py` reproduces the review PDF using ReportLab, a dependency only for PDF authoring.
